# Kundengewinnung Region Bretzfeld / Hohenlohe / Heilbronn

Ausgangslage: Anfang 2027 drei Kunden sicher. Kapazität ~3 Projekte/Monat. Engpass = Anfragen.
Einzugsgebiet ~25 km: Bretzfeld, Öhringen, Pfedelbach, Neuenstein, Obersulm, Weinsberg, Heilbronn.

## Zielgruppen (nach Passung)
| Zielgruppe | Aufhänger | Passendes Angebot |
|---|---|---|
| **Weingüter, Wengerter, Besenwirtschaften** | Öffnungszeiten, Saison, Weinverkauf | Website + Speisekarte + 3D-Aufsteller, ggf. Weinshop (Altersprüfung beachten) |
| **Gastronomie** | Karte nur als PDF, keine mobile Seite | Gastro-Paket |
| **Handwerk** | Fachkräfte- und Azubi-Mangel | Website mit Karriere-/Bewerbungsseite |
| **Hofläden, Direktvermarkter** | Vorbestellung, Abholung | kleiner Shop / Bestellformular |
| **Praxen, Dienstleister, Ferienwohnungen** | Termine, Vertrauen, Buchung | Business-Paket |
| **Vereine** | Sichtbarkeit, Mitglieder | günstige Referenz, Empfehlungen ins Dorf |

## Kanäle (Priorität)
1. **Empfehlungen**: Bestandskunden + 3 neue Kunden aktiv fragen, Empfehlungsbonus (z. B. 1 Monat Pflege gratis).
2. **Eigene lokale Sichtbarkeit**: Google-Unternehmensprofil, Bewertungen sammeln, Seiten „Webdesign Bretzfeld / Öhringen / Heilbronn / Hohenlohe".
3. **Persönliche Ansprache**: Liste aus Google Maps, Website prüfen, vorbeigehen oder Brief (keine Kalt-E-Mails, UWG).
4. **Netzwerke**: Gewerbe-/Handelsverein bzw. BdS-Ortsverband (falls vorhanden), IHK Heilbronn-Franken, Wirtschaftsförderung Hohenlohekreis, Gewerbeschauen.
5. **Partner**: Fotografin, Druckereien, Werbetechnik/Beschriftung, IT-Dienstleister ohne Webdesign, Steuerbüros.
6. **Präsenz vor Ort**: Weinfeste, Märkte, Vereinssponsoring mit Logo/Link.

## Leadliste (einmalig aufbauen, wöchentlich pflegen)
Spalten: Name · Branche · Ort · Website vorhanden? · Problem (mobil, langsam, kein SSL, veraltet, PDF-Karte) · Kontaktweg · Status · Nächster Schritt · Datum.
Ziel: 150 Einträge bis Ende Januar.

## Trichter (Annahme)
10 Kontakte/Woche/Person = ~80/Monat → ~10–15 Gespräche → ~2–3 Abschlüsse.
